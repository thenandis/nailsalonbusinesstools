🖥️ Web Server Deployment

Simple Deployment: No server-side processing required. Any web server capable of serving static files will work.

🚀 Apache HTTP Server

Setup Instructions:

  1. Copy entire application folder to your web root (e.g., /var/www/html/)
  2. Ensure Apache is configured to serve static files
  3. Set appropriate permissions:
    sudo chown -R www-data:www-data /var/www/html/nail-salon-tools/ sudo chmod -R 755 /var/www/html/nail-salon-tools/

Optional .htaccess Configuration:

# Enable compression AddOutputFilterByType DEFLATE text/html text/plain text/xml text/css text/javascript application/javascript application/json # Set cache headers ExpiresActive On ExpiresByType text/css "access plus 1 month" ExpiresByType application/javascript "access plus 1 month" ExpiresByType image/png "access plus 1 year" ExpiresByType image/ico "access plus 1 year"

⚡ Nginx

Basic Configuration:

server { listen 80; server_name your-domain.com; root /var/www/nail-salon-tools; index CHNSC_StartPage.html; # Enable gzip compression gzip on; gzip_types text/css application/javascript application/json text/html; # Cache static assets location ~* \.(css|js|png|ico)$ { expires 1M; add_header Cache-Control "public, immutable"; } # Serve main application location / { try_files $uri $uri/ /CHNSC_StartPage.html; } }

Deployment Steps:

  1. Copy application folder to /var/www/nail-salon-tools
  2. Update Nginx configuration
  3. Test configuration: nginx -t
  4. Reload Nginx: systemctl reload nginx

🖥️ IIS (Windows Server)

Setup Process:

  1. Open IIS Manager
  2. Right-click "Default Web Site" → Add Application
  3. Set Alias: nail-salon-tools
  4. Set Physical Path to application folder
  5. Ensure MIME types are configured for .json, .map files

☁️ Cloud Platform Deployment

Cloud-Ready: The application is designed for easy deployment on all major cloud platforms.

🌐 Netlify (Recommended for Simple Deployment)

Method 1: Drag & Drop

  1. Visit netlify.com and create account
  2. Drag and drop the entire application folder to Netlify dashboard

🔐 HTTPS Setup

Security Requirement: Always serve over HTTPS in production, especially for business applications handling sensitive data.

Let's Encrypt (Free SSL)

# For Apache/Nginx on Ubuntu/Debian sudo apt install certbot python3-certbot-apache # For Apache sudo apt install certbot python3-certbot-nginx # For Nginx # Generate certificate sudo certbot --apache -d yourdomain.com # For Apache sudo certbot --nginx -d yourdomain.com # For Nginx # Auto-renewal sudo crontab -e 0 12 * * * /usr/bin/certbot renew --quiet

⚡ Performance Optimization

Compression Setup

  • Gzip: Enable for CSS, JS, HTML files
  • Brotli: Better compression for modern browsers
  • Expected Savings: 70-80% size reduction
# Nginx Brotli example load_module modules/ngx_http_brotli_filter_module.so; load_module modules/ngx_http_brotli_static_module.so; http { brotli on; brotli_comp_level 6; brotli_types text/css application/javascript text/html application/json; }

Caching Strategy

  • Static Assets: 1 year cache (versioned files)
  • HTML: No cache or short cache
  • Service Worker: Handles offline caching
# Nginx caching example location ~* \.(js|css)$ { expires 1y; add_header Cache-Control "public, immutable"; } location = /CHNSC_StartPage.html { expires -1; add_header Cache-Control "no-cache, no-store, must-revalidate"; }

🧪 Testing & Validation

✅ Pre-Deployment Checklist

  • File Integrity: Verify all files are present and not corrupted
  • Permissions: Ensure web server can read all files
  • MIME Types: Verify .json, .map files serve correctly
  • HTTPS: Confirm SSL certificate is valid and redirects work
  • Compression: Test that gzip/brotli is working
  • Mobile Testing: Verify responsive design on various devices
  • Browser Testing: Test in Chrome, Firefox, Safari, Edge
  • Language Switching: Verify both English and Vietnamese work
  • Save/Load: Test data persistence across browser sessions
  • Export Functions: Verify CSV export works correctly

    • 🔍 Troubleshooting Common Issues

    Application Won't Load

    • Check browser console for JavaScript errors
    • Verify all static files are accessible (404 errors)
    • Ensure MIME types are configured correctly
    • Check for CORS issues if serving from subdomain

    Blank Page or Loading Issues

    • Verify JavaScript files are loading correctly
    • Check Content-Security-Policy headers
    • Ensure service worker isn't caching old version
    • Clear browser cache and test in incognito mode

    Save/Load Not Working

    • Check LocalStorage permissions in browser
    • Verify HTTPS is enabled (required for some storage APIs)
    • Test in different browsers to isolate issues
    • Check browser storage quotas

    Update Process: To update to a new version, simply replace the application files and clear browser caches.

    Zero-Downtime Update Process

    1. Create backup of current version
    2. Upload new version to temporary directory
    3. Test new version thoroughly
    4. Atomically switch directories (symlink or rename)
    5. Verify update completed successfully
    6. Clear CDN cache if applicable
