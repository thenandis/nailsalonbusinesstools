🚀 Quick Start Guide

Easy Setup: No installation required! Simply open CHNSC_StartPage.html in your web browser.

💻 Desktop/Laptop Instructions

  1. Download & Extract: Unzip the application folder to your desired location
  2. Open Application: Double-click on CHNSC_StartPage.html
  3. Choose Language: Select English or Vietnamese from the language selector in the top-right
  4. Select Your Location: In the W2 vs 1099 Model, choose your California city/county from the Minimum Wage Selection section
  5. Start Planning: Navigate between the three main tools using the navigation tabs

💰 Using the Minimum Wage Feature

  1. Navigate to W2 vs 1099 Model: Click the W2 vs 1099 tab in the navigation
  2. Find Minimum Wage Section: Look for the collapsible "Minimum Wage Selection" section at the top
  3. Select Year: Choose 2025 or 2026 from the year dropdown
  4. Search Locality: Type your city name in the locality search box (e.g., "San Francisco")
  5. Optional - Small Employer: If your business has 25 or fewer employees, check "Use Small Employer Rate" if available
  6. Automatic Update: Watch the W2 Hourly Wage field update automatically with your selected minimum wage

📤 Managing Minimum Wage Data

  1. Expand Tools: Click "▼ Min Wage Data Tools" in the Minimum Wage section
  2. Download: Click "📥 Download Current Data" to get the minwage.json file
  3. Edit: Open the file in a text editor and add 2027 data or new localities
  4. Upload: Click "Upload" button and select your edited JSON file
  5. Reset: Click "🔄 Reset" to restore original built-in data

📱 Mobile Device Instructions

⚠️ Important: This React app cannot be opened directly from your phone's file manager or Files app. Opening the HTML file directly will show a blank screen. This is due to browser security restrictions for local files.

✅ Working Methods for Mobile Access:

🌐 Method 1: Web Hosting (Recommended)

  1. Deploy to free hosting: Netlify or Vercel
  2. Access via https:// URL on mobile browser
  3. Works perfectly on all devices
  4. Add to Home Screen for app experience
  5. Best for: Permanent deployment

💻 Method 2: Desktop + Mobile WiFi

  1. Open app on desktop (double-click HTML file)
  2. On same WiFi, access from mobile browser
  3. Use desktop's local IP address
  4. Example: http://192.168.1.100
  5. Best for: Local testing

🚀 Method 3: Simple Python Server

  1. Install Python on desktop
  2. Run: python -m http.server 8000
  3. Access from mobile: http://desktop-ip:8000
  4. Both devices on same WiFi
  5. Best for: Developers
Why doesn't direct file opening work? React apps need a web server to properly load JavaScript modules. Modern browsers block local file access for security. This is standard for all React/modern web applications.

❌ What Doesn't Work:

  • iOS Files App: Tapping HTML file shows blank screen
  • Android File Manager: Opening HTML file usually fails
  • File:// Protocol: Not supported for React apps
  • Email Attachments: Won't work when opened directly

All tools include comprehensive save and load functionality with custom naming.

🆘 Troubleshooting & Support

Common Issues & Solutions

App Won't Load

  • Ensure you're opening CHNSC_StartPage.html
